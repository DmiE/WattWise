# Session history (S-06)

User can view a scrollable, read-only list of their completed sessions across
all plans — newest first — each row showing date, session type, logged duration,
subjective rating, and km ridden. Nice-to-have / secondary success criterion
("feels like a real training log"). Read-only query over existing tables; no
schema, migration, or API-route changes.
