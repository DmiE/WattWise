# Intensity reference (S-07)

User can expand an inline reference within the session detail view to see zone
definitions (power-meter / HRM users) or the RPE scale (no-equipment users).
Content adapts to the user's declared equipment. Nice-to-have; static content,
no data-model or API changes.
